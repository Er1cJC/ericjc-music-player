# 需求说明

## 项目定位

本项目实现一个面向毕业设计的跨平台音乐播放器系统，覆盖 Web 和 macOS 桌面端，保留 Windows 桌面端打包能力。

## 角色

- 普通用户：浏览音乐、播放音乐、管理歌单、收藏歌曲。
- 管理员：管理歌曲、专辑、歌手、封面、歌词和用户。

## 核心功能

- 用户注册、登录。
- 歌曲列表、搜索、分类。
- 播放、暂停、上一首、下一首、进度条、音量。
- 歌词展示。
- 收藏歌曲。
- 创建歌单、添加歌曲到歌单。
- 播放历史。
- 后台上传歌曲、封面和歌词。

## 第一版范围

- 播放器主界面。
- 模拟歌曲列表。
- 基础播放控制。
- 后端歌曲列表接口。
